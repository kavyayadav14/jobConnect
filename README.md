# JobConnect

JobConnect is a responsive job portal web application built using **HTML, CSS, and JavaScript**. It allows users to browse jobs, search and filter job listings, view job details, and submit job applications.

## Features

* Browse available job listings
* Search jobs by job title, company, or skills
* Filter jobs by category and location
* Sort jobs by salary
* View detailed job information
* Apply for jobs through an application form
* Store submitted applications using Local Storage
* View submitted applications
* Responsive design for different screen sizes

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* DOM Manipulation
* Local Storage
* URL Parameters

## How It Works

1. Users can browse available jobs from the home page or jobs page.
2. Jobs can be searched by title, company, or required skills.
3. Users can filter jobs by category and location.
4. Jobs can be sorted according to salary.
5. Users can open a job to view complete job details.
6. Users can submit an application through the application form.
7. Submitted applications are stored in the browser using Local Storage.
8. Users can view their submitted applications on the applications page.

## Current Project

This version of JobConnect is developed using **HTML, CSS, and JavaScript** with browser-based Local Storage for application management.
